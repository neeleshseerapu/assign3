Steps to Build:
1. Create a square function that returns a button. This will be the basic building block of the board.
2. Then export a function called board, this will have all the content to be displayed. Create three divs and name them board-row.
3. Fill the the three divs with three square components each.
4. Using react's useState, create a state for the squares the board contains as an array of 9 nulls. This array will contain the values of each of the 9 squares.
5. Update the square function to take two arguments, one for the value of the square, and one for the function that will be triggered when a square is clicked. The value will be passed in by the square components in each board row, from the square state in the board function.
6. The function to be passed in to the square's onClick will be defined in the board. When handling a click, there should be a check whether that sqaure already has a value.
7. Before we handle the click, we need to also create a state variable in the board that determines whether the next move is an X. Now, in our function to handle the click, if the square is empty, we will update the squares array with a copy that has the clicked square's value updates with either 'X' or 'O' depending on the state.
8. Lastly, we need to create a calculate win function. Start by defining all the winning lines, and then looping through those lines to see if 'X' or 'O' has all three squares in a line, returning the value that made the winning line. Add a check if the game is won at the end of the board functions internals. Have it update the display text with the player that won, and if the game is not over, display the next player who should move. Also check if the game has already been won whenever a square is clicked and prevent further action if it has been won. This works because the page rerenders after each change to the state, so the check will run when the squares array is updated.
