1. First, add a state to the board that keeps track of the number of moves that have been executed already. This will help us separate the game into two phases, before six moves finished, and after six moves finished.
2. For the first six moves, the game should function like normal tic-tac-toe. Wrap it in an if-statement and create an else statement for the moving phase of the game. Add a state to track whether the click is the first or second click of a two click sequence. If it is the first click, the state should be null. If it is the second click, then the state should contain the number of the square that was clicked first.
3. Now, for the phase of the game after six moves. Create a function in the board to check if a move consisting of a start and end position is a valid adjacent move.
4. At the end of the adjacent check function, check if the center of the board is occupied. If the adjacent move does not win the game while the center is occupied, then do not allow the move. Also, exempt square 4 from this check as it a move that originates from the center must leave the center empty.
5. Add the calculate win function to the phase 2 else block, and the game is complete.
